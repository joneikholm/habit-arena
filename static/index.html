Habit Arena

How to log data a model can learn from
  1. Few fields, logged every day. 4–6 fields beat 15 that get skipped. A missing day hurts more than a missing field.
  2. Log at the same time of day. For example, evening mood always just before bed.
  3. Prefer a choice of 3 over a number that is a guess. "poor / medium / good" is easier to log honestly than "6.5 out of 10".
  4. Order the options from low to high and set ordered: true when there is a natural order. Use ordered: false only when there truly isn't one; it costs one column per option (one-hot).
  5. Keep a field's meaning fixed. Don't change what "late" means halfway through. Need a new meaning? Add a new field.
  6. Pick things that could plausibly affect the target. The model can only find what you log.
  7. A field added later starts empty for the earlier days; those days get the field's mean so far, so the model learns little from it until it has a week or two of its own data.
  8. Log the target every day, including day 1. Without it, the day can't be used for training or scoring.
